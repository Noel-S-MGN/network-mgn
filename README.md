# network-mgn

This repository includes a comprehensive documentation file containing all the basic troubleshooting commands commonly used in networking, such as:

show running-config

show ip interface brief

ping

traceroute
…and many more.

These commands are essential for network diagnostics and general configuration checks.

🧪 Packet Tracer File
Also included is a Cisco Packet Tracer (.pkt) file in which all the above commands are preloaded and ready to test. You can open this file in Cisco Packet Tracer to view or simulate the configurations and practice troubleshooting directly in a lab environment.
